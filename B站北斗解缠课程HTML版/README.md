# B 站北斗解缠课程 · HTML 图文笔记版

UP 主 **北斗解缠** 的缠论入门/初级/中级课程合集（`BV1YK4y1M7C6`）共 43 集，
每集一份**单文件自足**的图文笔记 HTML：图片全部以 base64 内嵌，可离线打开、
可直接打印成 PDF，无需任何外部依赖。

由 [`video-slides-to-deck`](../video-slides-to-deck/) skill 生成。

## 怎么用

| 想做的事 | 做法 |
|---|---|
| 读某一集 | 直接双击 `P01.html` … `P43.html` |
| 看原视频对应片段 | 目录里每节右侧的 **↗ 跳视频** 按钮、或卡片头部的时间标签，点一下直接跳到 B 站该集对应时间点 |
| 对照讲师原话 | 每节底部「展开本节原始字幕」 |
| 打印 | 浏览器 `Ctrl+P`，已适配 A4（自动隐藏字幕区） |
| 打印成 16:9 PDF | Branch A 的 storyboard 版式已适配 16:9；本套是文字版，A4 更合适 |

## 内容口径（重要）

- **截图**：原视频是屏幕录像（讲师在思维导图 / 行情图上边讲边手绘），每节配该节
  讲到关键处的那一帧，配图与文字一一对应。
- **字幕**：B 站官方 `ai-zh` AI 生成轨，同音错字较多（例：「背词」＝背驰、「二脉」＝二买、
  「比」＝笔、「租个底」＝筑个底）。笔记正文已按上下文逐条归正，**字幕折叠区保留原始
  AI 文本**以便对照。
- **语气**：讲师的限定表述（「有望」「不一定」「可能」）全部原样保留，未拔高成断言。
- 本套是**课程笔记**，不构成任何投资建议；原视频讲师同样未给出收益承诺或荐股。

## 关于体积

43 份合计约 **230 MB**——因为每份都内嵌了全部关键帧的 base64 PNG。
这是「单文件自足、离线可用」的直接代价：换来的是任何机器上双击即开、不丢图。

## 生成方式

```powershell
python ..\video-slides-to-deck\scripts\srt_segmap.py   pXXsub.srt --out segmap.json --cuts ...
python ..\video-slides-to-deck\scripts\build_notes.py --segmap segmap.json --notes notes.json \
       --out notes_pXX.html --root .
```

`build_notes.py` 在任一节缺内容 / 无字幕 / 图缺失 / 段落重叠时会 **exit 1 且不写文件**，
所以批量跑不会静默产出半成品页面。
